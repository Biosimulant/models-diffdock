# Expected Outputs

Successful runs should produce:

- `pose_summary` with ranked pose rows
- `confidence_summary` with the top-pose confidence score and confidence band
- `structure_artifacts` with `top_complex_file`, `top_pose_file`, and copied `rank_*_file` entries
- a `structure3d` visual for `top_rank_complex.pdb`
- a summary `table` visual for rank and confidence information
